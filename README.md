# 🗄️ Banco de Dados (Database Repository)

Bem-vindo ao repositório **Banco de Dados**! 

Este espaço é dedicado a armazenar projetos, scripts SQL, modelagens e exercícios focados no design, manipulação e análise de dados. Ele reflete a aplicação prática de conceitos de Desenvolvimento de Sistemas e Análise/Engenharia de Dados, servindo como um portfólio de soluções para problemas reais de negócio.

## 📌 Sobre o Repositório

O objetivo principal deste repositório é demonstrar o domínio sobre o ciclo de vida dos dados, desde a estruturação inicial até a extração de insights. Aqui você encontrará:
- **Modelagem de Dados:** Criação de esquemas relacionais, diagramas (MER/DER) e normalização.
- **Definição de Dados (DDL):** Scripts de criação e alteração de tabelas, índices e restrições.
- **Manipulação de Dados (DML):** Rotinas de inserção, atualização e exclusão de registros.
- **Análise Exploratória (DQL):** Consultas avançadas utilizando *Joins*, *CTEs* (Common Table Expressions), *Window Functions* e agregações para extração de relatórios e métricas.

## 🛠️ Tecnologias e Ferramentas

* **Linguagens:** SQL, Python *(para automação, limpeza de dados com Pandas e conexão com o banco)*.
* **SGBDs (Sistemas de Gerenciamento de Banco de Dados):** MySQL, PostgreSQL, SQLite *(edite com os que você mais utiliza)*.
* **Conceitos Focados:** Arquitetura de Dados, ETL (Extract, Transform, Load), Otimização de Consultas.
